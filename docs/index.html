📋 Descripción técnica

MercApp es una aplicación web de catálogo de productos (similar a Mercado Libre simplificado) construida como SPA con Vue 3 + Pinia + Vue Router en el frontend y una API REST con Express + Mongoose en el backend, con persistencia en MongoDB Atlas.

🎨

Frontend

Vue 3, Vite, Pinia, Vue Router — desplegado en Netlify con SPA fallback

⚙️

Backend

Node.js, Express, Mongoose — desplegado en Railway con Nixpacks

🗄️

Base de datos

MongoDB Atlas M0 — usuario dedicado, TLS activo, allowlist mínima

📄

Micrositio

GitHub Pages — carpeta /docs con arquitectura, endpoints y guía local

🔌 Endpoints de la API

Base URL producción: https://mercappv2-production.up.railway.app

MétodoRutaDescripciónBody / Query
GET/healthHealth check del servidor y DB—
GET/api/productsListar productos?search=&categoryId=
GET/api/products/:idObtener producto por ID—
POST/api/productsCrear producto{ name, price, category, stock, description, imageUrl }
PUT/api/products/:idReemplazar producto completomismo que POST
PATCH/api/products/:idActualización parcialcampos a modificar
DELETE/api/products/:idEliminar producto—
GET/api/categoriesListar categorías—

🚀 Ejecución local

Requisitos

  • Node.js ≥ 18
  • MongoDB local en localhost:27017 o cadena Atlas

Backend

cd backend
cp .env.example .env          # configurar MONGODB_URI y PORT
npm install
npm run seed                  # poblar BD (12 productos, 5 categorías)
npm run dev                   # http://localhost:3001

Frontend

cd frontend
cp .env.example .env          # VITE_API_URL=http://localhost:3001
npm install
npm run dev                   # http://localhost:5173

🔑 Variables de entorno

Backend — Railway

MONGODB_URI=mongodb+srv://...
PORT=3001
FRONTEND_URL=https://legendary-dolphin-57251e.netlify.app

Frontend — Netlify

VITE_API_URL=https://mercappv2-production.up.railway.app

⚠️ Nunca subir .env al repositorio. El archivo .env.example (sin credenciales) documenta las variables requeridas.
